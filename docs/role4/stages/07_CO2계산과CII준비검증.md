# 7단계 | CO2 계산 Tool과 CII 준비 검증

## 역할 범위와 이번 목표

사용자와 담당 범위를 다시 확인해 LLM 선정·설치·연결을 보류하고 역할 4의 정형 데이터·DB·Python Tool에 집중했습니다. 기존 시제품에도 간단한 배출량 함수가 있었지만 실제 역할 4 자료에 맞는 출처·결측·연료 분류 검증이 필요했습니다. 이번에는 별도 계산 모듈과 인증 API를 만들고 공식 CII 판단을 할 수 없는 이유를 응답으로 제공했습니다.

구현 파일은 service/role4_calculations.py입니다. 입력을 검증하는 Pydantic 모델, 계수 카탈로그, DB 읽기 함수 calculate, 산술 함수 compute를 분리했습니다. 모델 응답이나 자연어 추출값이 아니라 DB의 승인된 입력과 명시한 연료 매핑으로 계산합니다.

## 실제 데이터를 먼저 확인한 이유

실제 MRV는 80,552행 모두 DWT가 없고 연료종류별 사용량도 없습니다. 기존 distance_nm_estimate는 연료와 거리당 지표를 역산한 값이라 검증 거리를 대신할 수 없습니다. 따라서 연간 CO2 원본 보고값을 보여 주는 것과 연료로 CO2를 다시 계산하는 것을 분리해야 합니다.

합성 Noon 4,380행의 연료 라벨은 MGO 730행과 VLSFO 3,650행입니다. 선종에는 Bulk carrier, Container ship, Oil tanker, Ro-ro ship이 있습니다. DWT가 있더라도 모든 선종의 공식 용량 기준을 DWT로 간주할 수는 없습니다. Ro-ro 등의 선종은 GT 등 기준을 추가 확인해야 하므로 이번 DWT 기간 지표에서 제외했습니다.

## 계수와 연료 매핑

IMO MEPC.364(79) §2.2.1에서 Diesel/Gas Oil 3.206, LFO 3.151, HFO 3.114 tCO2/t-fuel의 고정 부분집합을 정리했습니다. 버전 식별자는 IMO-MEPC364-79-2.2.1-FOSSIL-SUBSET-v1입니다. GET /api/role4/factors로 값·버전·출처를 확인할 수 있습니다. 최신 규정 전체나 모든 연료를 지원하는 카탈로그는 아닙니다.

MGO와 VLSFO는 입력 라벨이므로 자동 매핑하지 않았습니다. 호출자가 연료 라벨, 선택한 계수 범주, 증빙 또는 개발용 가정을 명시해야 합니다. VLSFO를 HFO로 넣는 예제는 오직 개발용 가정입니다. 실제 연료 적용성을 검증했다는 의미가 아니며 응답에도 mapping_verified=false로 표시합니다. 한 연료라도 매핑되지 않으면 일부 합계를 전체 배출량으로 반환하지 않습니다.

## DB 조회와 계산 절차

1. 앱 관리자 세션과 CSRF를 확인합니다. 단일 선박과 MRV 단일 연도 또는 Noon 날짜 범위를 검증합니다.
2. role4 승인 뷰에서 전체 범위를 읽습니다. 화면의 20행 페이지와 독립적이며, 연간 365행도 한 스냅샷에서 모두 읽습니다. 1000행을 넘으면 잘라 계산하지 않고 거절합니다.
3. READ ONLY/REPEATABLE READ와 문장당 5초 제한을 적용합니다. 출처 파일과 해시를 입력에 포함합니다.
4. 합성 데이터는 연료별 사용량에 CF를 곱한 뒤 합산합니다. Decimal 정밀도 50자리로 계산하고 최종 표시값만 소수 6자리로 반올림합니다.
5. 양수 총거리·동일 DWT·허용 선종인 경우 CO2_t × 1,000,000 / (DWT_t × 거리_nm)의 개발용 기간 지표를 제공합니다.
6. 계산식·버전·매핑 근거·원본 입력을 응답에 담고 public 감사 이력에 요청 요약을 남깁니다. role4와 원본 자료는 수정하지 않습니다.

## 계산 가능·불가를 나누는 방법

실제 MRV는 원본 보고 CO2를 source_reported_co2_t로 반환할 수 있지만 재계산 CO2는 null이고 누락 항목을 안내합니다. 여러 연간 기록이 겹칠 가능성이 있으면 자동 합산하지 않습니다. 합성 데이터에서는 거리 0인 날의 연료를 제외하지 않습니다. 총거리 0이면 CO2는 계산하고 집약도는 null로 둡니다.

날짜가 중복되면 계산을 차단합니다. 요청 기간 중 일부 날짜가 없으면 누락 경고를 반환하고 실제 존재하는 기록만 계산합니다. 누락일을 0으로 채우거나 연간 수치로 확대 추정하지 않습니다. official_cii와 official_cii_rating은 항상 null이며 규정 적합성은 not_assessed입니다.

## 검증과 후속 인수인계

독립 손계산 사례는 HFO 10t와 Diesel/Gas Oil 5t입니다. 결과는 47.170t CO2이고 DWT 1000t·거리 100nm에서는 471.7gCO2/(DWT t·nm)입니다. 단위·반올림·0값·미매핑·용량 불일치·권한을 테스트하고 실제 DB에서 한 선박 365일 입력을 SQL 합계와 대조합니다. 이는 산술 검증이며 합성 자료로 공식 CII를 검증한 것은 아닙니다.

팀에 전달할 명세는 docs/role4/CALCULATION_TOOL.md입니다. POST /api/role4/calculate의 scope와 fuel_mappings, 응답의 blocker·snapshot을 사용하면 됩니다. LLM이나 기존 조회 도우미에 자동 연결하지 않았습니다. 팀 Agent 담당자는 권한과 매핑 근거를 유지하는 방식으로 별도 연동할 수 있습니다.

다음에는 실제 연료 분류 증빙, 검증 거리와 DWT 또는 GT, 적용 선종, 연간 DCS 범위, 보정·제외, 연도별 기준선·감축·등급 규칙을 확보해야 합니다. 현재 확보되지 않은 값은 임의로 보충하지 않았습니다.

근거 문서: IMO MEPC.364(79) §2.2.1의 연료 계수, MEPC.352(78) G1의 배출량·용량·거리 구조, IMO CII 안내. 공식 원문 URL과 API 예제는 CALCULATION_TOOL.md에 수록했습니다. 사용자 입력 매핑의 정확성이나 최신 규정 적용성까지 자동으로 인증하지 않습니다.
