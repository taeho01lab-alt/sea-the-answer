# 역할4 전용 배포 검증

검증일: 2026-09-30

## 교체 범위

- 원격 main의 기존 기준 커밋: `7c9a517522022143f1eb428d280513b71d7c8280`.
- 기존 MVP·문서검색·보고서·웹 화면을 제거하고 역할4 코드·계약·단계 문서·PDF만 구성.
- 로컬 작업 중인 원래 저장소와 실제 PostgreSQL 데이터는 변경하지 않음.
- 조회·계산 핵심 로직은 기존 역할4 구현에서 가져옴. HTTP 래퍼를 독립 FastAPI로 분리하고 세션/CSRF 대신 서버 간 Bearer 토큰 인증 적용.
- 실제 LLM은 미연결. 고정 scope 조회 도우미는 규칙 경로만 제공.

Python 3.12.14의 새 가상환경에 의존성을 설치한 뒤 동일한 47개 테스트와 전처리 3개 테스트를 다시 통과했습니다. 설치 버전은 `requirements.lock.txt`에 보존했습니다.

## 범위와 한계

원본·전처리 데이터의 외부 재배포 조건은 미확정이므로 데이터 자체를 포함하지 않습니다. 새 PC에서 전체 데이터 조회를 재현하려면 안내에 따라 팀 보유 데이터와 PostgreSQL을 준비해야 합니다. Linux 적재, 외부 서비스 운영, 실제 LLM, 공식 CII 계산·등급 판정은 이번 배포 검증에 포함되지 않습니다. 과거 PDF의 앱 실행·화면 설명은 역사적 기록이며 현재 README가 실행 기준입니다.
